# Space Shepherd (Space Animals)
Scripts for the space animals from the Game Jam "All the Way Up" (January 2026)<br>
Since the project was a teamproject, I only uploaded part of my code. The code was used to control the space animals, i.e., space sheep, black sheep and the wolf. All classes share a common base (SpaceAnimal). BlackSheep inherits from Spacesheep. I also created the gamelogic, the logic for the menu and levels. Here, only the SpaceAnimal code is shown.
